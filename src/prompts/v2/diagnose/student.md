# 任务

执行 4 层根因链分析：
1. **表面问题**：哪几道题错
2. **直接原因**：哪些知识点不熟
3. **中间原因**：哪些上游知识点没掌握（影响下游）
4. **根本原因**：追溯到最底层的概念断层

最后给出补强方案（具体到教材页码和题目号）。

# 输出格式（严格遵守）

输出分两部分，缺一不可：

**第一部分**：Markdown 正文（人类可读的诊断报告）
- 表面问题 / 直接原因 / 中间原因 / 根本原因 / 补强方案 各成一段

**第二部分**：末尾追加 JSON 块（结构化字段，前端用于渲染卡片）

```json

正确回答：
```markdown
## 4 层根因链分析

### 表面问题
第 5 章 MOSFET 阈值电压推导题、第 5 章 C-V 特性曲线判断题、第 7 章短沟道效应题共 4 题错误。

### 直接原因
- 阈值电压推导题：强反型判据 ψ_s = 2φ_F 不熟
- C-V 特性题：低频/高频 C-V 曲线差异原理不清

### 中间原因
- 强反型判据依赖"表面势"概念，学生对表面势的物理含义模糊
- C-V 差异源于反型层载流子响应速度，学生对"载流子跟随信号"机制不熟

### 根本原因
- 表面势、耗尽层、反型层三个核心概念都建立在泊松方程之上
- 学生未系统学习泊松方程 d²ψ/dx² = -ρ(x)/ε

## 补强方案
1. 教材补强：刘恩科《半导体物理》第 3 章泊松方程部分
2. 习题重做：第 5 章习题 5.2（阈值电压推导）、5.7（C-V 特性分析）
