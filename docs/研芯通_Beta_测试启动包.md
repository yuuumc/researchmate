# 二、测试任务清单

以下 4 条主链路覆盖研芯通核心功能，请**逐条完成并打勾**。每条任务后附有「重点关注」——这是本次 Beta 重点验证的三个技术改造点，你的反馈直接决定这些功能能否上线。

## 任务 1 ｜ 诊断链路：找到你的薄弱点

* [ ] 登录后进入首页，选择**「智能诊断」**入口

* [ ] 输入一个你真实薄弱的知识点（如"MOS管阈值电压搞不清""数字电路时序分析总是错"），完成一轮诊断对话

* [ ] 查看诊断报告：**4 层根因链**（表面→直接→中间→根本）是否准确？诊断分数是否合理？

* [ ] 查看补强方案：推荐的教材、习题是否对症？

**重点关注 · P0\-1 GraphRAG 知识图谱检索**：诊断报告中会显示知识图谱路径（如「半导体基础 → … → MOSFET 阈值」）。请确认：① 路径中的知识点是否与你的问题相关；② 系统是否引用了知识库内容（非胡编乱造）。如果路径完全不相关或引用内容明显错误，请记下来。

## 任务 2 ｜ 导师链路：苏格拉底式概念引导

* [ ] 进入**「教研答疑」**（或「导师」入口），输入一个概念性问题（如"MOS管的开启电压怎么回事"）

* [ ] 观察回复：是否采用了**苏格拉底式引导**（先提问引导思考，再逐步讲解），而非直接给答案？

* [ ] 查看知识图谱路径和知识库引用是否出现，内容是否相关

**重点关注 · P0\-3 三层记忆召回**：如果你在任务 1 做过诊断，再在任务 2 问相关问题，系统应该**记住你之前的诊断内容**。请留意回复中是否出现类似"我记得你上次诊断时……"的表述。如果有，说明记忆召回生效；如果没有，请记录——这是本次测试最核心的验证点。

## 任务 3 ｜ 规划链路：生成学习计划

* [ ] 进入**「学习规划」**入口（或在诊断后选择「生成学习计划」）

* [ ] 查看生成的计划：是否基于你的诊断结果？时间安排是否合理？

* [ ] 检查计划中是否包含**具体到知识点的任务**（而非泛泛的"复习第一章"）

**重点关注 · P0\-2 工具调用**：规划生成过程中，系统会调用多个 Agent 工具（诊断数据读取、知识库检索、计划编排）。如果规划内容与诊断结果脱节、或出现明显的格式混乱/重复内容，可能是工具调用链路异常，请记录。

## 任务 4 ｜ 升学链路：就业 / 升学导航

* [ ] 进入**「就业咨询」**入口

* [ ] 输入你的专业方向和意向（如"微电子科学与工程，想了解半导体行业就业"）

* [ ] 查看就业路径分析：是否结合了你的学科背景？薄弱点自检清单是否有用？

* [ ] 尝试**高频切换**：快速在「智能诊断 → 就业咨询 → 教研答疑」之间来回切换 2–3 次，看系统是否稳定不报错

## 加分项 ｜ 跨链路记忆验证（强烈建议）

* [ ] 用同一账号先做一次诊断（任务 1），隔几分钟后再去「教研答疑」问同一知识点的相关问题

* [ ] 观察系统回复是否**引用了之前的诊断结论**（如"你上次诊断时这个知识点得分 XX"）

* [ ] 再换一个完全不同的知识点提问，确认系统**不会张冠李戴**（不把 A 知识点的记忆错误引用到 B 知识点）

这一项直接验证 P0\-3 三层记忆的**召回准确性**，是比赛演示的核心场景。你的反馈对团队价值极高。

# 三、如何反馈

**统一反馈入口：**[点击填写反馈表单](https://larkcommunity.feishu.cn/base/WwpRbMgoGaAE2js0Ho2cXYEVnWh)

每发现一个问题或有一个建议，就提交一条记录。请按以下**三级口径**选择问题严重度：

|级别|含义|举例|响应承诺|
|---|---|---|---|
|**🔴 阻断**|功能完全不可用、报错、数据丢失|登录失败、页面白屏、诊断报错、提交后无响应|24 小时内修复|
|**🟡 体验**|功能可用但体验差、不符合预期|响应太慢（\>15 秒）、布局错位、回复质量低、移动端显示异常|Beta 末期统一排期|
|**🟢 建议**|功能正常，你有改进想法|希望增加某功能、交互可以更顺手、文案可以更清晰|收集评估，后续迭代|

**反馈填写要点：**① 写清你用的是哪个账号（学霸/中等/差生）；② 描述操作步骤（做了什么 → 发生了什么）；③ 阻断级问题建议截图或录屏。越具体，修复越快。
