| 决策 | 落实点 |

## 四、集成步骤（队长版）

1. **下载 tarball**，解到工作目录
2. **覆盖 8 文件**到 `yanxintong/` 仓库根（保留目录结构即可）
3. **`npm install`** 拉 `@supabase/supabase-js@^2.39.0`
4. **填 `.env`**：复制 `.env.example` 为 `.env`，填 `VITE_SUPABASE_ANON_KEY`（在飞书云文档 / Vercel 环境变量取）
5. **`node --check`** 6 个 .js 文件全过（已自验）
6. **`npm run build`** 应该过；如有路径 import 报错，检查 `jsconfig.json` / `vite.config.js` 的 `@` 别名是否已含 `services` 和 `composables`
7. **v2.0 第二 commit**：
   ```bash
   git add src/services/ src/composables/ src/stores/auth.js src/stores/profile.js package.json .env.example
   git commit -m "feat: v2.0 data layer - Supabase 直连 + 4 真实分支"
   git push origin main
   ```
8. **不在本轮范围**：UI 组件（6 视图 + 弹窗）留 v2.5 轮

## 六、字段映射（profile v1.5 → profiles.metadata）

`profiles` 表只有 6 个非 metadata 字段，其余 v1.5 字段全进 `metadata` jsonb：

| profile 字段 | 入表位置 | 备注 |
|---|---|---|
| `user_id / role / phone / name / avatar_url` | 顶层 | profiles 表原生字段 |
| `major / target_direction / target_school / target_major` | `metadata.*` | v1 字段 |
| `learning_style / preparation_stage` | `metadata.*` | v1 正式版新增 |
| `exam_date` | `metadata.*` | ISO 字符串 |
| `ability_stars` | `metadata.*` | `{ [topic]: 1-5 }` |
| `weak_topics / mastered_topics` | `metadata.*` | 数组 |
| `last_diagnosis_score / last_diagnosis_date` | `metadata.*` | — |

`fromRow()` 把 metadata 平铺回顶层，前端 store 字段形态保持不变。
