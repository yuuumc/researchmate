## 第 2 段：5 Agent 协作演示 + 知识图谱（0:30-1:30，60 秒）

### 画面

打开 https://researchmate.vercel.app，展示仪表盘首页（能力进度条 + 考研倒计时 + 快捷提问入口）。

### 操作 + 配音

**(0:30-0:50) 概念问题 + 知识图谱路径（Tutor Agent）**

输入框输入："MOSFET 阈值电压怎么推导？"

> "第一个场景，学生问概念问题。系统走 Tutor Agent，RAG 检索后通过知识图谱反查目标节点，递归构建前置知识链——从半导体基础、能带理论到 MOSFET 基础共 11 个前置节点。每个节点标注掌握状态，给出焦点提示'建议先补半导体基础'。这就是从'问题→文本→回答'升级到'问题→知识节点→前置知识→回答'。"

展示 Markdown 回答 + 知识图谱路径卡 + RAG 引用切片 + Agent Trace 时间线。

**(0:50-1:10) 学习诊断（Diagnose Agent）**

清空对话，输入："我半导体物理考了 55 分，MOSFET 阈值电压推导错，C-V 特性错，短沟道效应不会"

> "第二个场景，学生考砸了。系统走 Diagnose Agent，调用 deepseek-reasoner 推理模型，做 4 层根因链分析——表面、直接、中间、根本原因，最后给出补强方案。诊断结果会写回学生认知模型，更新能力星级。"

展示诊断报告卡片（score / weak_points / root_causes / remediation）。

**(1:10-1:30) 科研成长（Research Agent）**

清空对话，输入："我以后想做 AI 芯片，给我一个科研路线图"

> "第三个场景展示第五个 Agent——科研成长。学生问 AI 芯片方向，系统输出本科阶段路线（数字电路→Verilog→FPGA）和研究阶段路线（RISC-V→AI Accelerator），还推荐相关论文和项目。这是研芯通从'考研工具'升级为'工科人才成长智能体'的关键。"

## 录制注意事项

1. **字体放大**：浏览器缩放到 125%，IDE 字体 16px+，确保评审席可读
2. **网络备用**：录屏时同时启动本地 dev server，网络卡顿时切到 localhost
3. **避免鼠标乱晃**：用键盘 Tab / Ctrl+L 定位，鼠标只在必要时移动
4. **配音清晰**：每段配音留 0.5 秒缓冲，避免与画面切换重叠
5. **总时长监控**：用秒表计时，第 4 段是关键（90 秒），超时则跳过 v3 规划细节
